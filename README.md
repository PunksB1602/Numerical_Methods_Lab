## Numerical Methods Lab (4th Semester, 2023/24)

This repository contains a set of C programs developed as part of my Numerical Methods laboratory in the 4th semester (2023/24). The primary aim of these programs is to provide hands-on experience with fundamental numerical algorithms for solving equations, curve fitting, interpolation, and matrix operations.

### Overview

The programs in this collection cover:

- **Curve Fitting:** Implementation of linear, parabolic, and exponential curve fitting using the method of least squares, allowing for the modeling of data trends.
- **Interpolation:** Lagrange's interpolation method for estimating unknown values within the range of a discrete set of known data points.
- **Solving Linear Equations:** Multiple approaches including factorization methods (Crout and Doolittle), direct methods (Gauss Elimination and Gauss-Jordan), matrix inversion using Gauss-Jordan, and iterative techniques (Jacobi, Siedel, and Power methods) for finding solutions to systems of linear equations.
- **Solving Non-Linear Equations:** Root-finding algorithms such as Bisection, Regula-Falsi (False Position), Secant, Fixed Point Iteration, and Newton-Raphson methods for solving non-linear equations numerically.
